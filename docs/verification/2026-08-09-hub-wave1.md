## Independent review closure

The independent review found four actionable issues:

1. compatibility contract schemas were missing from the wheel;
2. deeply nested unknown metadata could escape as `RecursionError`;
3. integral JSON numbers written with a decimal were rejected by `integer` schemas;
4. validated documents shared nested mutable values with caller input.

Each issue received a regression test before its fix. The final 182-test run includes those regressions and passes.
