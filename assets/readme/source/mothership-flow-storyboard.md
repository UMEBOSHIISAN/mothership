# Mothership 日本語説明GIFの絵コンテ

この資料と `generate_mothership_flow.py` は、READMEに置く説明用GIFと
静止画ポスターの決定的な生成元です。実行結果の証拠や外部操作の記録では
ありません。

## 伝える順番

1. AI・呼び出し側が操作案を用意する
2. Mothershipがリポジトリ、PR番号、元コミット識別子、対象ブランチ名、統合方法を固定する
3. 人間が承認または拒否を判断する
4. 判断をローカル台帳へ記録する
5. 同じ信頼された台帳履歴内で一度だけ取り出し、二度目は停止する
6. 別途構成した実行系が外部状態を変更する
7. 別経路の確認系が外部状態を読み取る
8. `github.merge_pr` の参照実装であり、汎用の実行系や本番安全性を主張しない

図の外側にある実行系・確認系は、公開パッケージに同梱されません。
base commit SHA、最終的な外部結果、人間本人の認証、台帳コピーをまたぐ
再利用防止を、この図が示すこともありません。
